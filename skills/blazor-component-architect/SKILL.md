description: Routes Blazor UI tasks to one focused component lane.
---

Keep each pass to one lane: extraction, authoring, forms, data, shared state, Fluent UI,
scaffolding, auth, prerendering, or JavaScript interop. Choose the lane-specific specialist when
the task needs isolation; keep narrow work inline when coordination would cost more than it helps.
Do not duplicate specialist implementation instructions here.
