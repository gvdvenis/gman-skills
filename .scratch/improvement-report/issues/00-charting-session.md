# Charting session: report purpose

Type: grilling
Status: resolved

## Question

What is the self-improvement report for, in the user's hands?

## Answer

Both review surface and prompt factory, with prompt-building as the point and review as navigation.

The user wants to easily see what went wrong and what needs improvement, decide which improvements
will actually be implemented by assembling a prompt with simple clicks, and then take that prompt
away in two forms:

1. a readable markdown version, and
2. a succinct, compressed form specifically tailored for use in an LLM prompt.

This makes the report's primary output the assembled prompt, not the analysis itself.
